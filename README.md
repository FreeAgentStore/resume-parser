# Resume Parser

Parse resumes into structured JSON — name, email, skills, experience, education. Heuristic evolved from 500+ resumes.

Part of [FreeAgentStore](https://freeagentstore.online) — AI tools that run free in your browser.

## Install

```bash
npm install @freeagentstore/resume-parser
```

## Usage

```ts
export { parseResume } from "@freeagentstore/resume-parser";
```

## ESM (zero install)

```html
<script type="module">
  import { ... } from 'https://freeagentstore.online/pkg/resume-parser/index.js'
</script>
```
